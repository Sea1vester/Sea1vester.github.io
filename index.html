WISL

Recorded flight evidence for mixed drone fleets

Aug 2026 to now

Lead developer with Inessa Wong · NUS Enterprise invite-only track

Different drone makers dump logs in totally different shapes (DJI, PX4, ArduPilot). We pull them into one schema, index the physics-based incidents, and a local Ollama model turns the repeats into a bulletin you can actually read before the next flight.

Anyway: The useful bit, for me, is that the evidence stays tied to the actual flight. The warning, from that airframe, in that sortie.

  • Python
  • FastAPI
  • Redis
  • CesiumJS
  • Ollama

Independent

Jun 2026 to now

A CLI and MCP server that leases parallel git worktrees for coding agents and keeps them on one shared, browser-reviewable plan. One change per loop. Failures get reverted. It only closes when tests pass.
