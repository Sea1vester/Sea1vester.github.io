# sea1vester.github.io

Personal logbook at [sea1vester.github.io](https://sea1vester.github.io).

## Changing the writing

All of the copy lives in `index.html`.
Each entry is one `<article class="card">` block: title, dates, a couple of paragraphs, then the `stuff used` list.

To update the live site:

1. Edit `index.html` (or `styles.css` if the look is off).
2. Commit and push to `main`.

You can also open `index.html` on GitHub and use the pencil button.
GitHub Pages usually refreshes within a minute.
